# GEOINT Vinh - Goi nhan dien Bui Quang Vinh

1. Giai nen ZIP vao `C:\Users\Admin\Documents\GEOINT_Vinh` (khong tao thu muc me).
2. Mo PowerShell trong thu muc du an va chay `python .\install_brand.py`.
3. Chay `python manage.py check` va `python manage.py runserver`.
4. Tai lai trang bang Ctrl+F5. Kiem tra WebGIS, OSINT Dashboard, AI Analysis.

Bo cai tu tim template trang chu co chuoi `GEOINT / 3D ATLAS` va 2 template OSINT/AI. Sao luu vao `backup_brand_...` truoc khi chen 2 tai nguyen static. Khong thay doi Python models, API, migration, token Cesium, CSS goc, hoac JavaScript nghiep vu.

Neu muon phuc hoi, chep cac template tu thu muc backup ve vi tri goc; hai tep brand-vinh.css/js khong con duoc tai neu template da phuc hoi.
